# 제품 명세

## 서비스

- 작업명: SpeakUp
- 이전 서비스명: TranslateUp (한→영 영작 평가, 이 기획으로 완전히 대체됨)

## 개요

SpeakUp은 토익 스피킹(TOEIC Speaking) 시험을 준비하는 학습자를 위한 AI 문제 생성·평가 서비스입니다. 사용자가 문제를 요청하면 AI가 매번 새로운 토익 스피킹 문제를 생성하고, 사용자는 실제 시험처럼 답변을 작성합니다. 제출한 답변은 AI가 즉시 채점하고 구체적인 피드백을 제공합니다.

이 서비스는 정해진 문제 은행을 반복 학습하는 방식이 아니라, 매 연습마다 새로운 문제로 실전 감각을 기르는 것을 목표로 합니다.

## 타겟 사용자

- 토익 스피킹 시험을 준비하는 한국어 사용자
- 문제 유형(Part)별로 반복 연습이 필요한 학습자
- 자신의 답변이 실제 채점 기준에서 어떤 평가를 받을지 궁금한 사용자

## 핵심 가치

- 문제를 외우는 대신 매번 새로운 문제로 연습합니다.
- 실제 토익 스피킹 채점 기준(발화 내용의 적절성, 문법, 어휘, 구성)에 맞춰 평가합니다.
- 점수만이 아니라 구체적으로 무엇을 어떻게 개선할지 설명합니다.
- 문항별로 즉시 피드백을 받아 학습 흐름이 끊기지 않습니다.

## 다루는 문제 유형 (MVP)

토익 스피킹은 총 11개 문항, Part 1~5로 구성되지만 MVP에서는 아래 2개 Part만 다룹니다.

### Part 3: 사진 보고 질문에 답하기 응용 — 대화문 기반 질의응답 (실제 시험의 Q4~Q6 유형)

- AI가 특정 상황(예: 지인과의 약속, 예약 변경, 행사 안내 등)에 대한 짧은 대화문 또는 안내문 맥락을 생성합니다.
- 그 맥락에 대한 질문 3개를 함께 생성합니다.
- 사용자는 질문마다 답변을 작성합니다.
- 질문마다 개별로 즉시 채점합니다.

평가 요소:

- 질문 의도에 맞는 답변인지
- 정보의 정확성과 완결성
- 문법과 어휘
- 답변 길이의 적절성 (실제 시험은 문항별 권장 답변 길이가 다름)

### Part 5: 문제 해결하기 (Propose a Solution)

- AI가 일상적인 문제 상황(약속 취소, 예약 오류, 물건 파손 등)을 설명하는 음성 메시지 상황을 텍스트로 생성합니다.
- 사용자는 문제를 인지했음을 표현하고, 해결책을 제안하는 답변을 작성합니다.
- 제출 즉시 채점합니다.

평가 요소:

- 문제 상황 인지 여부
- 해결책 제안의 타당성과 구체성
- 문법과 어휘
- 발화 구성(문제 인지 → 해결책 → 마무리)

## MVP 범위

첫 버전은 한 페이지 웹 앱으로 만듭니다.

포함하는 기능:

- 서비스 소개 Hero 섹션과 시작 버튼
- Part 3 / Part 5 유형 선택
- `/api/generate`를 통한 AI 문제 자동 생성 (Part3: 상황+대화 맥락+질문 3개, Part5: 문제 상황 설명)
- 텍스트 답변 입력 (Part3는 질문별 입력창, Part5는 단일 입력창)
- `/api/evaluate`를 통한 AI 평가 (문항 단위 즉시 평가)
- 평가 결과 표시 (점수, 항목별 피드백, 모범 답안 예시)
- 새 문제 생성 버튼
- 로딩, 입력 검증, 오류 상태
- 학습 안내
- FAQ

MVP에서 제외하는 기능:

- Part 1, 2, 4 (음성 낭독, 사진 묘사, 정보 활용 설명)
- 마이크 녹음, 음성 답변, 발음/억양 평가
- 사용자 계정, 로그인
- 학습 기록 저장, 히스토리
- 결제
- 관리자 페이지
- 랭킹, 연속 학습일, 게임화 요소

## 평가 원칙

AI 평가는 다음 규칙을 따라야 합니다.

- 실제 토익 스피킹 채점 기준(내용 적절성, 문법, 어휘, 구성, 답변 길이)에 맞춰 평가합니다.
- 텍스트로 입력된 답변을 평가 대상으로 하며, 발음·억양·유창성은 평가하지 않습니다.
- 점수와 함께 구체적인 개선 포인트를 제공합니다.
- 모범 답안 예시를 제공하되, 유일한 정답처럼 강요하지 않습니다.

## 성공 기준

- 사용자가 Part 3 또는 Part 5 유형을 선택할 수 있습니다.
- 선택한 유형에 맞는 문제(상황, 질문 또는 문제 설명)를 AI가 즉시 생성합니다.
- 사용자가 문항별로 텍스트 답변을 제출할 수 있습니다.
- 빈 답변, 생성 실패, 평가 실패는 명확한 메시지로 안내합니다.
- 평가 중에는 중복 제출을 막습니다.
- AI 평가는 종합 점수, 항목별 점수, 모범 답안, 피드백을 반환합니다.
- 결과는 원본 JSON이 아니라 보기 좋은 UI로 표시합니다.
- 사용자는 새 문제를 다시 생성할 수 있습니다.
