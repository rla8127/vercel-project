# 제품 명세

## 서비스

- 작업명: TranslateUp
- 한글 서비스명 후보: 영작 트레이너, 영작한판
- 최종 서비스명: TranslateUp

## 개요

TranslateUp은 한국어를 사용하는 초급부터 중급 수준의 영어 학습자를 위한 영작 연습 서비스입니다. 사용자는 한국어 문장을 보고 직접 영어 문장을 작성한 뒤, AI에게 의미 전달, 문법, 자연스러움에 대한 평가를 받습니다.

이 서비스는 영작을 하나의 정답만 있는 퀴즈로 다루지 않습니다. 한국어 원문의 의미를 잘 전달하고 자연스러운 영어라면 여러 표현을 정답으로 인정해야 합니다.

## 타겟 사용자

- 한국어를 사용하는 영어 학습자
- 초급부터 중급 수준의 학습자
- 모범 답안만 보는 것이 아니라, 자신이 쓴 문장의 문제점을 구체적으로 알고 싶은 사용자

## 핵심 가치

- 사용자가 쓴 문장에서 무엇이 잘못됐는지 설명합니다.
- 올바른 대체 표현은 그대로 인정합니다.
- 사용자의 문장이 이미 문법적으로 정확하고 자연스럽다면 불필요하게 수정하지 않습니다.
- 의미 전달, 문법, 자연스러움을 나누어 피드백합니다.

## MVP 범위

첫 버전은 한 페이지 웹 앱으로 만듭니다.

포함하는 기능:

- 서비스 소개 Hero 섹션과 시작 버튼
- 난이도 선택
- 초급과 중급 난이도
- 프로젝트 안에 저장된 정적 한국어 문제 목록
- 영어 답변 입력
- `/api/evaluate`를 통한 AI 평가
- 평가 결과 표시
- 다음 문제 버튼
- 로딩, 입력 검증, 오류 상태
- 학습 안내
- FAQ

MVP에서 제외하는 기능:

- 고급 난이도
- 사용자 계정
- 학습 기록 저장
- AI 문제 생성
- 결제
- 관리자 페이지
- 랭킹, 연속 학습일, 게임화 요소

## 난이도

### 초급

초급 문제는 짧고 기본적인 한국어 문장을 사용합니다.

예시:

- 한국어: 나는 주말마다 친구를 만난다.
- 예시 답안: I meet my friends every weekend.

평가 요소:

- 주어와 동사
- 시제
- 단수와 복수
- 기본 전치사

### 중급

중급 문제는 이유, 선호, 경험이 포함된 문장을 사용합니다.

예시:

- 한국어: 나는 시간을 절약할 수 있기 때문에 온라인 쇼핑을 선호한다.
- 예시 답안: I prefer shopping online because it saves me time.

평가 요소:

- 접속사
- 문장 구조
- 어휘 선택
- 자연스러운 표현

### 고급

고급 난이도는 MVP에서는 구현하지 않습니다.

예시:

- 한국어: 시간이 더 있었다면, 나는 새로운 기술을 배우는 데 더 많은 시간을 투자했을 것이다.
- 예시 답안: If I had had more time, I would have spent more time learning new skills.

## 평가 원칙

AI 평가는 다음 규칙을 따라야 합니다.

- 사용자 답변을 모범 답안과 글자 단위로 비교하지 않습니다.
- 한국어 원문의 의미가 전달됐는지 평가합니다.
- 영어 문법이 올바른지 평가합니다.
- 실제 영어 표현으로 자연스러운지 평가합니다.
- 모범 답안과 표현이 다르다는 이유만으로 감점하지 않습니다.
- 사용자의 문장이 이미 문법적으로 정확하고 자연스럽다면 억지로 고치지 않습니다.

반드시 포함할 지시문:

```text
문법적으로 정확하고 자연스러운 문장은 수정하지 마세요. 모범 답안과 표현이 다르다는 이유만으로 감점하지 마세요.
```

## 성공 기준

- 사용자가 초급 또는 중급 난이도를 선택할 수 있습니다.
- 선택한 난이도에 맞는 한국어 문장이 표시됩니다.
- 사용자가 영어 답변을 제출할 수 있습니다.
- 난이도 미선택, 빈 답변, 한글만 입력한 답변은 명확한 메시지로 막습니다.
- 평가 중에는 중복 제출을 막습니다.
- AI 평가는 종합 점수, 항목별 점수, 추천 문장, 전체 피드백, 수정할 부분을 반환합니다.
- 결과는 원본 JSON이 아니라 보기 좋은 UI로 표시합니다.
- 사용자는 다음 문제로 이동할 수 있습니다.
