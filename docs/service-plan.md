# 서비스 기획서

## 1. 서비스 아이디어

**SpeakUp**은 토익 스피킹(TOEIC Speaking) 시험을 준비하는 학습자를 위한 AI 문제 생성·평가 서비스입니다.

정해진 문제은행을 반복해서 외우는 기존 학습 방식 대신, 사용자가 연습을 요청할 때마다 AI가 새로운 상황의 문제를 즉석에서 생성합니다. 사용자는 실제 시험처럼 텍스트로 답변을 작성하고, 제출 즉시 AI가 실제 토익 스피킹 채점 기준에 맞춰 점수와 구체적인 피드백을 돌려줍니다.

## 2. 목적

- 토익 스피킹 학습자가 **매번 새로운 문제**로 실전 감각을 기르게 합니다.
- 점수만 주지 않고 **무엇을, 왜 고쳐야 하는지** 구체적으로 설명합니다.
- 문항 단위로 **즉시 피드백**을 제공해 학습 흐름이 끊기지 않게 합니다.

## 3. 타겟 사용자

- 토익 스피킹 시험을 준비하는 한국어 사용자
- Part 3(대화문 기반 질의응답), Part 5(문제 해결하기) 유형을 반복 연습하고 싶은 학습자
- 자신의 답변이 실제 채점 기준에서 어떤 평가를 받을지 궁금한 사용자

## 4. 페이지/섹션 구성 및 메뉴 이동

한 페이지(Single Page) 웹 앱이며, 상단 고정 헤더의 내비게이션으로 아래 4개 섹션을 이동합니다.

| 섹션 | 앵커 경로 | 내용 |
| --- | --- | --- |
| 홈 (Hero) | `#home` | 서비스 소개, 시작하기 버튼 |
| 연습하기 | `#practice` | Part 3 / Part 5 선택 → AI 문제 생성 → 답변 입력 → AI 평가 |
| 학습 안내 | `#guide` | 토익 스피킹 채점 기준(내용/문법·어휘/구성) 설명 |
| FAQ | `#faq` | 서비스 이용 관련 자주 묻는 질문 |

헤더에는 섹션 이동 메뉴 외에 **다크 모드 토글 버튼**(🌙/☀️)이 있어, 언제든 화면 테마를 전환할 수 있습니다.

## 5. 핵심 기능

- Part 3(대화문 기반 질의응답) / Part 5(문제 해결하기) 유형 선택
- AI 기반 문제 자동 생성 — 요청마다 새로운 상황·인물·소재
- 문항 단위 텍스트 답변 입력 및 즉시 AI 평가
- 종합 점수, 항목별 점수(내용/문법/어휘), 모범 답안, 개선 포인트, 전체 피드백 표시
- 빈 입력, 한글만 입력, API 오류, 응답 지연 상황에 대한 안내 메시지
- 평가/생성 중 중복 제출 방지(버튼 비활성화, 로딩 문구)
- 모바일/데스크톱 반응형 UI
- 라이트/다크 모드 (시스템 설정 자동 감지 + 수동 토글, 선택값 유지)

## 6. AI 기능 정의

이 서비스는 AI 기능을 **문제 생성**과 **답변 평가** 두 가지로 나누어 제공합니다. 두 기능 모두 프론트엔드(`js/app.js`)가 `fetch`로 백엔드(Python, Vercel Serverless Functions)를 호출하고, 응답을 화면에 렌더링하는 동일한 구조를 따릅니다.

### 6-1. 문제 자동 생성 — `POST /api/generate`

- **입력**: 문제 유형(`part`: `part3` 또는 `part5`)
- **처리**: OpenAI에 유형별 프롬프트를 전달하고, 구조화된 JSON(`json_schema`) 출력을 강제해 매번 새로운 상황을 생성합니다.
- **출력**
  - Part 3: 상황 설명, 대화문, 질문 3개
  - Part 5: 문제 상황(음성 메시지 형태 텍스트), 핵심 문제 요약
- **사용자 가치**: 문제를 외우지 않고 매번 낯선 상황에서 실전처럼 연습할 수 있습니다.
- **실패 처리**
  - 지원하지 않는 유형 → `400` + "지원하지 않는 문제 유형입니다."
  - OpenAI 호출 실패/응답 파싱 실패/타임아웃 → `500` + "문제를 생성하지 못했습니다. 잠시 후 다시 시도해 주세요."

### 6-2. 답변 평가 — `POST /api/evaluate`

- **입력**: 문제 맥락(Part3는 상황+대화문+질문, Part5는 상황+문제 요약) + 사용자가 작성한 영어 답변
- **처리**: 실제 토익 스피킹 채점 기준(내용 적절성, 문법, 어휘, 답변 구성)을 명시한 프롬프트로 OpenAI에 평가를 요청하고, 구조화된 JSON으로 점수와 피드백을 받습니다.
- **출력**: 종합 점수, 항목별 점수(내용/문법/어휘), 모범 답안, 개선할 부분 목록, 전체 피드백
- **사용자 가치**: 정답과 글자 단위로 비교하는 채점이 아니라, 실제 시험 기준에 가까운 평가와 개선 방향을 즉시 받을 수 있습니다.
- **실패 처리**
  - 빈 답변 → `400` + "답변을 입력해 주세요."
  - 한글만 입력한 답변 → `400` + "영어로 답변을 작성해 주세요."
  - OpenAI 호출 실패/타임아웃 → `500` + "평가 중 오류가 발생했습니다. 잠시 후 다시 시도해 주세요."
  - 응답이 30초 이상 지연되면 프론트엔드가 자체적으로 요청을 중단하고 "응답이 지연되고 있습니다. 잠시 후 다시 시도해 주세요." 안내

### 6-3. 프론트엔드-백엔드 연동 방식

- 프론트엔드는 `fetch("/api/generate", { method: "POST", ... })`, `fetch("/api/evaluate", { method: "POST", ... })`로 백엔드를 직접 호출합니다.
- `response.ok`이면 JSON 응답을 파싱해 문제 카드 또는 평가 결과 블록을 화면에 렌더링합니다.
- `response.ok`가 아니면 서버가 반환한 `error` 메시지를 그대로 사용자에게 보여줍니다.
- 요청마다 `AbortController`로 30초 타임아웃을 걸어 응답 지연 상황을 자체적으로 처리합니다.
- 요청이 진행 중인 동안 해당 버튼을 비활성화해 중복 제출을 막고, 로딩 문구로 진행 상태를 알립니다.
