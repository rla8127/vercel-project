    FAQ

    AI 평가는 이렇게 동작합니다.

    모범 답안과 다르면 무조건 감점되나요?

    아니요. 의미가 맞고 자연스러운 영어라면 다른 표현도 정답으로 인정합니다.

    이미 맞는 문장도 고치나요?

    문법적으로 정확하고 자연스러운 문장은 억지로 수정하지 않도록 평가 기준에 넣었습니다.

    API 키는 어디에 저장하나요?

    OpenAI API 키는 코드에 쓰지 않고 Vercel 환경 변수 `OPENAI_API_KEY`로 설정합니다.
