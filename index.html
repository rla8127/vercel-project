FAQ

SpeakUp은 이렇게 동작합니다.

같은 문제가 반복되나요?

아니요. 문제 만들기를 누를 때마다 AI가 새로운 상황과 질문을 생성합니다.

마이크로 말해서 답해야 하나요?

MVP 버전은 텍스트 입력으로 답변합니다. 발음과 억양이 아닌 내용, 문법, 어휘, 구성을 평가합니다.

API 키는 어디에 저장하나요?

OpenAI API 키는 코드에 쓰지 않고 Vercel 환경 변수 `OPENAI_API_KEY`로 설정합니다.
